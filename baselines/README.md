# Baselines

This directory is reserved for deterministic comparison artifacts: synthetic policy scenarios, generated landmark fixtures, and any future static dictionary/video fallback provider. Baseline code and assets must never be imported by the production provider package by default.

The current `evaluation/` runner and `data/processed/` synthetic landmark set are legacy baseline candidates identified in `docs/REMOVAL_AND_MIGRATION_PLAN.md`; they are not moved in this architecture-only change.
